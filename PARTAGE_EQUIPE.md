# Simulateur Prodecta - version équipe

Cette archive contient la version compilée du simulateur de devis Prodecta.

## Utilisation

- Héberger le dossier `dist/` sur un hébergement statique, Netlify, Vercel, OVH, ou un serveur interne.
- Pour un test local depuis le projet : lancer `npm run preview` après `npm run build:share`.

Les devis sauvegardés restent dans le navigateur de chaque utilisateur via `localStorage`.
